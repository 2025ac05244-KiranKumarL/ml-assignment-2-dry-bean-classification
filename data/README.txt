DATASET FOLDER

You do not have to manually download the dataset if internet access is available.

Run:
    python model/train_models.py

The script will try to fetch UCI Dry Bean dataset ID 602 automatically and save:
    data/Dry_Bean_Dataset.csv

If the system has no internet access, manually place one of these files here:
    Dry_Bean_Dataset.csv
    Dry_Bean_Dataset.xlsx
